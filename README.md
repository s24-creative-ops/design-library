# Design Library – bisherige URLs

Die gemeinsame [Design Library](https://scout24-creative-ops.github.io/design-library/) wird jetzt unter `scout24-creative-ops/design-library` veröffentlicht. Sie enthält E-Mail-Module, LP-Module und Design-Tokens.

Dieses Repository erhält ausschließlich die bisherigen URLs. Seine drei HTML-Einstiege leiten zur neuen Library weiter; Querystrings und passende Hash-Routen bleiben erhalten. Der frühere Contentful-Einstieg öffnet direkt die LP-Module.

Die bisherigen CSS-, JavaScript- und Bilddateien bleiben für bestehende Direktlinks unverändert verfügbar. Hier keine neuen Module oder weiteren Library-Versionen pflegen.

Nicht löschen, umbenennen, privatisieren oder GitHub Pages deaktivieren, solange die bisherigen URLs weiter funktionieren müssen.
